# 关卡与音频设计

## 关卡节奏

| 关卡 | 块数 | 学习重点 |
| --- | --- | --- |
| 1–10 | 3–6 | 大块、轮廓、直边与基础斜边，熟悉拖起放大和吸附 |
| 11–20 | 6–7 | 从轮廓识别图案，房屋、帆船、小鱼、花朵等 |
| 21–30 | 7–8 | 大轮廓中的分区、凹形与局部组合 |
| 31–40 | 9–10 | 更相似的颜色与形状、多条接缝的组合 |
| 41–50 | 11–12 | 综合运用，保留足够的单块触控面积 |

50 关共有 391 块。生成器的最低面积约束为 0.68，实际最小值约 0.77；棋盘面积为 16。另以面积/周长限制过于狭长的形状。数据使用确定种子，重复生成可得到相同结果。

生成过程先设计主体形状，再将背景三角化并合并成大块，最后按阶段对大块进行受限分割。每块为不带孔的单连通多边形；全部块恰好覆盖目标方框。

运行时支持**等价解**：只要全部块在框内、无重叠且完整覆盖即可成功，不强制逐块回到原设计坐标。提示图展示原设计图案，吸附靠近设计坐标时优先辅助。

```powershell
python -m pip install numpy shapely pillow fonttools
python tools/generate_levels.py
```

生成器需要 Shapely 2.1 的约束三角化功能；已在本机执行。目录中 `level-report.json` 提供每关名称、块数和最小面积，`level-gallery.html` 提供完整图案预览。

难度是设计排序，自动测试验证可拼合性和几何质量；真实玩家用时、提示使用率和后期难度仍需要试玩数据评估。

## 吸附与通关

- 初始色块保持原尺寸，在下方集中叠放；优先缩小整堆轮廓和占用面积，允许底层大幅覆盖。每块至少露出 12% 面积，且露出区域能容纳半径 0.20 世界单位的抓取圆，避免只剩细边或尖角；该范围仅用于开局排布。拿起后，玩家可在可见游戏区域任意移动、重叠，随意拖进或拖出棋盘；没有固定的回收区和格子。
- 拖拽期间保留抓取点。从初始化到拿起、放下均保持拼图原尺寸。满足合法候选时才吸附，否则留在松手位置。取消操作恢复原状态，屏幕边缘只约束抓取点保持可触达。
- 每次释放优先检查目标位置，再检查已放置块与外框的平行边和端点。
- 斜边交会使用二元线性方程求位移，不再分别硬改 X/Y。
- 只在找到候选且候选合法时设置吸附状态；没有边匹配时不会虚报吸附。
- 使用统一 100000 倍整数坐标进行 Clipper 几何运算，无需等待物理碰撞体同步。
- 通关检查实际注册的游戏块，要求数量正确、尺寸为棋盘尺寸、并集与目标框吻合；面积容差为 0.0002 世界单位平方。
- 不对几何结果进行膨胀修补，所以实际缺口不会被人工填掉。

## 界面、品牌和屏幕适配

游戏名「色块拼图 / COLOR BLOCKS」。中文 Logo、拼块徽标、图标和配套素材使用 Codex 内置 image_gen 生成；完整提示词在 `Brand/README.md`。

使用雾蓝背景与纸白棋盘，主按钮为薄荷绿。游戏过程去掉重来按钮，完成后才出现继续入口。背景不再不断生成浮动方块，装饰保持静止。

提示图使用带 `CanvasRenderer` 的 `PolygonGraphic` 在 UI 内绘制，不注册任何游戏碰撞体。回归测试采样预览拼块内部像素，避免只有弹窗文字显示而图案不可见。

`PuzzleScreen` 统一计算安全区域、顶部/底部预留空间、世界相机及 HUD 缩放。宽屏限制内容列宽；相机同时保证棋盘和初始色块完整可见。提示预览、广告确认弹窗使用相同的安全区域规则。默认竖屏，不启用横屏旋转。

顶部只保留关卡名称。底部 `PuzzleDrawer` 参考旧 `SlideUpPanel` 的把手和滑动方式，默认收起，支持点击、上滑、下滑和平滑展开；滑动距离按 Canvas 缩放换算。展开只覆盖临时操作区，不移动相机或已有色块；切换关卡、拿起色块及通关均保留菜单开合状态，只有玩家点击把手或滑动才改变。关闭后隐藏的控件不拦截点击。眼睛、扬声器、静音及导航箭头用 `PuzzleIcon` 绘制矢量几何，无需新贴图。眼睛角标表示剩余次数，耗尽后显示播放标记和 +1，点击后仍需确认才播放激励视频。

游戏名仍为「色块拼图」。当前没有加载场景，关卡内不展示游戏名或 Logo；既有 Logo 作为品牌素材保留。

本地验证覆盖 360×640、375×667、393×852、412×915、720×1600、1080×2400、768×1024、1000×1000，包含模拟刘海及底部手势区。它验证布局与渲染，不代表这些实体手机、设备性能或抖音右上角宿主按钮已验收。

## 音频

《晨光拼色 / Morning Mosaic》是本次用代码创作并合成的器乐循环，未使用外部曲目或采样录音。

| 文件 | 内容 | 时长 |
| --- | --- | --- |
| `morning_mosaic.ogg` | C 大调、108 BPM、24 小节；轻拨奏、柔和铃音、低音与轻节奏 | 53.333 秒 |
| `click.ogg` | 滤波噪声与短低频木质触碰声，按键和拾取反馈，无高音铃声 | 0.095 秒 |
| `snap.ogg` | 上行双音，拼块吸附反馈 | 0.480 秒 |
| `powerUp1.ogg` | 上行和弦短句，关卡完成反馈 | 1.300 秒 |

保留三个旧音效文件名和 GUID，便于已有引用继续工作。背景音乐改为新资源路径。旧背景音乐保存在 `LegacyAudio`，不参与发行资源。

音频信号尾部按循环长度回绕到开头，避免补静音形成断点；实际播放仍需在最终宿主验证解码和循环衔接。音乐立体声压缩内存加载，短音效单声道解压加载；所有 AudioSource 为 2D。

```powershell
# 需要本机 ffmpeg 在 PATH 中
python tools/generate_audio.py
```

`audio-report.json` 记录生成时长、峰值和均方根；合成 PCM 未削波，Unity 导入已验证。听感仍建议结合手机扬声器和耳机确认音量。

## 语言和背景

所有玩家可见的运行时文案通过 `GameText` 和 `LocalizedLabel` 读取语言表；维护步骤见 `LOCALIZATION.md`。

`Config/Backgrounds.json` 配置四个背景资源。`BackgroundComponent` 在关卡开始时从上一张以外的背景中随机选择，局内不会跳变；Sprite 缓存复用并随组件销毁释放。贴图导入上限 1024，无 mipmap，压缩存储。三张新增 AI 背景提示词见 `Brand/background-prompts.json`。

原尺寸初始布局由 `tools/generate_opening_layouts.py` 离线生成，输出 `Config/OpeningLayouts.json`，游戏启动只读取位置和绘制顺序。重新生成关卡后必须重新生成初始布局。

## 字体

`Assets/Resources/Fonts/BlocksUI.ttf` 来自 Google Fonts 的 Noto Sans SC，实例化为常规字重并按项目中文内容裁剪，改名为 Blocks UI。保留了 SIL OFL 许可文件 `OFL.txt`。

来源：https://github.com/google/fonts/tree/main/ofl/notosanssc

新增中文文案时，运行 `tools/build_ui_font.py` 更新子集；源字体需放在 `.validation/Fonts/NotoSansSC.ttf`。当前子集约 192 KB，不依赖设备是否安装中文字体。
